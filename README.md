# MediBloom – Hospital Management System

A pastel-themed hospital management dashboard built with React, JavaScript, Vite, React Router and CSS.

## Run locally
1. Install Node.js (LTS).
2. Extract this project and open the folder in VS Code.
3. Open the terminal in the project folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL shown in the terminal (usually http://localhost:5173).

## Demo login
- Email: `admin@medibloom.com`
- Password: `medibloom`

## Features
- Responsive pastel dashboard
- Patient directory: add, search and remove patients
- Doctor directory
- Appointment booking and cancellation
- Department directory
- Billing overview
- Workspace settings
- Browser localStorage persistence for patient and appointment changes

## Tech stack
- React 18
- Vite 6
- JavaScript
- React Router
- Lucide React icons
- CSS

## Important note
This is a frontend academic/demo project. Data is stored in the browser using localStorage and the login is a demo flow, not secure authentication. For real hospital use, connect a backend, database, role-based access control, secure authentication, audit logs and appropriate privacy/security safeguards. Do not enter real patient or medical data into this demo.
